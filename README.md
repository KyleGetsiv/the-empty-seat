# The Empty Seat

A research-grade website tracking Waymo's operational metrics, unit economics, and financial picture. Built for growth investors and competitive AV operators who want primary sources, not press releases.

See [`dev-plan.md`](./dev-plan.md) for the full build specification and [`CLAUDE.md`](./CLAUDE.md) for project conventions used by Claude Code.

## Getting started

Copy `.env.local.example` to `.env.local` and fill in credentials, then:

```bash
npm install
npm run dev
```
